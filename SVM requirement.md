# SVM Coursework Requirements

Transcribed from handwritten classroom notes. The assignment has two parts: a literature review and an experiment. These are assignment reference materials, not instructions for repository maintenance.

## Part 1: SVM Literature Review

### Step 1: Collect Materials
- Collect **3–5 papers** about SVMs.
- Include supporting slides or lecture notes.

### Step 2: Summarize SVMs and Their Variants
- Basic ideas.
- Mathematical formulations and modeling.
- Advantages and disadvantages.

### Step 3: Research Directions and Personal Views
- Summarize current research directions based on Step 2.
- Present your own opinions.

### Format
- Approximately **5,000 English words**, with a minimum of **3,000 words**.
- Include references.

## Part 2: SVM Experiment

### Step 1: Describe the Data
- Identify the selected dataset.
- Explain the classification task.

### Step 2: Describe the Method
- Explain the SVM method used.
- Include a model description and pseudocode.

### Step 3: Present and Analyze Results
- Run and report results for **C = 1, 50, 100, 1000**.
- Present tables and graphical demonstrations.
- Include detailed analysis and discussion.

## Supplementary Suggestions

These suggestions were not explicitly stated in the classroom notes:

- Cite sources in the literature review and avoid plagiarism. The 3,000-word requirement is a minimum, not a target.
- Compare all four C values using the same dataset and kernel. Discuss the tradeoff between the margin and misclassification as C increases.
- Include decision-boundary and support-vector visualizations, as well as bar charts comparing accuracy or other metrics across C values.
